## Info

This repository holds the installer and source code for BettrFG, a Fall Guys BepInEx mod that aims to make the Fall Guys experience more fun using custom QoL features and UGC customization.

> [!NOTE]
> As of now, all published versions of the mod are only available in English.

## Installation

1. Get the installer from the [releases page](https://github.com/oreyre9000/BettrFG/releases/tag/installer).
2. Open the installer's executable file.
3. Select the installation location of your choice for the mod.
4. Choose whether to install the latest version, a specific version, or uninstall, etc.

## Features

- **Custom UGC** skins and accessories
- **Nametag** customization
- **Custom phrases** and image emoticons
- **Game appearance** customization (UI, main menu, background recolours)
- **Personal Best** saving and listing
- **In-game leaderboard**

### 2.0.0 and further (currently not released publicly, but in the repository):
- **Replay mode**
- **Pets**
- **Asset extraction in-game**
- ...and more

## Controls

| Input | Action |
| :--- | :--- |
| <kbd>Shift</kbd> + <kbd>Z</kbd> | Toggle tabs |
| <kbd>Z</kbd> | Toggle side-wheel (also unlocks the game cursor if it's stuck) |
| **Right click** | While the top of a tab has a white hover tint, right click it to open a list of tabs to switch to |
